# 🏡 Airbnb NYC Data Insights Project

A full-stack data analysis and visualization project using Python (Pandas) and Power BI.  
It demonstrates data cleaning, EDA, and dashboard development.

---

## 🔧 Tools Used

- Python (Pandas, Matplotlib)
- Power BI
- Git & GitHub
- VS Code

---

## 📊 Dashboard Charts

| Chart Name                        | Description                                    |
|----------------------------------|------------------------------------------------|
| ✅ Room Type Distribution         | Shows listing count by room type              |
| ✅ Price Range Histogram          | Simulates histogram using grouped price bins  |
| ✅ Listings by Borough (Pie)      | Proportions of listings across NYC boroughs   |

---

## 📁 Project Files

| File                          | Description                      |
|-------------------------------|----------------------------------|
| `eda_cleaning.py`             | Clean missing data and outliers |
| `eda_overview.py`             | Quick statistical summary        |
| `airbnb_cleaned.csv`          | Cleaned dataset                  |
| `Airbnb_Data_Insights.pbix`   | Power BI dashboard               |
